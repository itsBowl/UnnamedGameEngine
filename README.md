# UnnamedGameEngine

Game engine project looking to support multiple graphics APIs and as a way to explore programming patterns.

The eventual goal is to produce a game in this engine

## Current Project Progress:
### Graphics
- OpenGL : Supported
    - GLSL : Supported
- DirectX12 : Supported
    - HLSL : Supported
- Vulkan : Not Supported
    - SPIR-V : Not Supported

### Physics
- Bullet3 : Research ongoing

### Models/Meshes
- Assimp : FBX/GLTF/OBJ supported

### Scripting
- Not yet
